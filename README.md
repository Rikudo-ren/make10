# MAKE 10 BATTLE / メイク10バトル

出された数字を四則演算でつないで目標値を作る、リアルタイム対戦パズル。
React + Vite + Tailwind CSS + Firebase Realtime Database（匿名認証）。
サイバー / HUD 風のネオン UI と、CC0 素材による BGM・効果音を同梱しています。

## 起動

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/index.html に単一ファイルで出力
```

## 主な機能

- ルーム作成 / 合言葉（6文字コード）で参加、GMが設定を変更
- 出題はソルバーで「必ず解ける」ことを事前チェック
- 早解き順に得点（順位傾斜 / 早押し / 一律）
- **ゲーム内チャット**（ロビー・対戦中・結果画面）
  - 送信すると全員の画面の**下から「名前＋コメント」が大きく流れる**（ゴッドフィールド風）
  - 同時に **COMMS LOG** にログが残るので、見逃してもあとから全員のコメントを確認できる
- **サウンドシステム**
  - BGM（トップ／対戦／結果）と効果音19種。すべて CC0 の外部アセットを加工して同梱
  - 画面右下の AUDIO SYSTEM から **BGM / 効果音の ON・OFF と音量**を個別に切り替え（端末ごとに保存）
  - ブラウザの自動再生制限に合わせ、最初のタップで自動的に有効化
- パス（降参）と取り消し（確認ダイアログなし・画面左側に配置）
- ひとり練習モード（オフライン）
- 順位がひと目で分かる六角バッジ（1位=金 / 2位=銀 / 3位=銅）とスコアボード

## デザイン

- フォント: Orbitron（見出し・数字）/ Chakra Petch（UI）/ 日本語は OS フォント
- 絵文字は使わず、ラインアイコン（`src/components/icons.tsx`）と `1位` `2位` `3位` の
  六角バッジで状態を表現
- 背景は遠近グリッド＋スキャンライン＋走査線のアニメーション（`prefers-reduced-motion` 対応）
- favicon / PWA アイコンは `public/`（`favicon.svg` から PNG を書き出し）

## メモ

- 問題生成はタイムスライス方式（10msごとに処理を手放す）なので、
  6桁×高難度の設定でもUIがフリーズしません（3秒で打ち切り・全員に準備中を表示）。
- チャットはルーム内の直近60件のみ。GMが退出するとルームごと削除されます。
- **誰もいないルームは自動で消えます**（最後の1人が退出すれば即時、タブを閉じた場合は約30〜50秒後）。
- 在室中のルームも **最終アクセスから24時間** で自動削除されます
  （`rooms/index` の期限を見て、アプリを開いたクライアントが掃除。Cloud Functions 不要）。
- 通信が切れても再接続時に在室が自動復元され、部屋が消えていた場合はトップへ戻ります。
