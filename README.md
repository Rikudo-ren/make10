# MAKE 10 BATTLE / メイク10バトル

出された数字を四則演算でつないで目標値を作る、リアルタイム対戦パズル。
React 互換 API（Preact）+ Vite + Tailwind CSS + Firebase Realtime Database（匿名認証）。
サイバー / HUD 風のネオン UI と、CC0 素材による BGM・効果音を同梱しています。

## 起動

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に出力（index.html は単一ファイル + 音声/フォント/アイコン）
npm run serve    # ビルド済み dist/ を gzip 付きで配信（確認用・PORT で変更可）
```

## 主な機能

- ルーム作成 / 合言葉（6文字コード）で参加、GMが設定を変更
- 出題はソルバーで「必ず解ける」ことを事前チェック
- 早解き順に得点（順位傾斜 / 早押し / 一律）
- 1問の制限時間は秒単位で設定可能（デフォルト3分／制限時間なしも可）。
  正解しても止まらない全員共通の経過時間と、自分の確定タイムを併せて表示する
- 結果画面のあと自動で次の問題を始める設定も可能（10秒カウントダウン、GMの端末が進行）
- **素因数分解モード**（ルーム対戦・ソロ練習の両方で「ゲームの種類」から切替）
  - 出された合成数に、素数を1つずつ入力（Enter）して素因数分解する早解き。進め方は設定で選択できる
    - **残りが見えない進め方**: 画面に出るのは「2×2×3=12」のような式の合計だけ。
      問題の数が割れて残りが減っていく表示はしない（残りが見えると簡単すぎるため）。
      積が目標とぴったり一致したら完了。積が目標を超える入力はそのまま積まれ、
      超えたことが分かるよう積が**赤く表示**される。目標の因数でない素数を積んでも指摘はされない
    - **割り算**: 目標が割られていき、残りの数を1にしたら完了。
      残りを割り切れない素数を入れると「含まれる素因数ではありません」と出る
    - どちらの式でも、14のような合成数を入れると「素数を入力してください」と出る
    - 画面キーパッド（×・0〜9・Enter）付き。×は入力中は1文字消し、入力が空のときは直近の素数を1つ消す
      （物理キーボードのBackspaceも同じ）。「最初から」で全リセットもできる
  - 設定: 分解する数の**桁数（2〜15桁／指定なし）**・素因数の**下限素数／上限素数（2〜997のすべての素数、3桁まで）**・**素因数の個数（最小〜最大／指定なし）**。
    「指定なし」の場合は、指定した側の条件に合う問題が出る（桁数なし=2〜15桁、個数なし=2〜10個）
  - 個人戦／チーム戦・途中参加・チャット・GM操作（強制パス／強制終了）はメイクテンと同じ部屋でそのまま使える
  - ソロ（ひとり練習）でも同じ設定・盤面で遊べる（クリアタイム計測と答え表示つき）
- **ゲーム内チャット**
  - 送信すると全員の画面の**下から「名前：コメント」の文字だけがゆっくり上へ流れる**（ゴッドフィールド風）。
    プレート・枠・背景などの吹き出しは出さず、**名前も途中で切らず全文表示**する
    （チャットログでも名前は省略しない）。流れる文字には**当たり判定が一切ない**ので、
    後ろにある数字タイルやボタンはそのまま押せる
  - 画面左下の **COMMS ボタン**（未読バッジ付き）でログを開いて読み返せる。
    ログには入力欄とクイック返信も入っているので、そこから送信もできる
  - 対戦中はプレイエリア下の1行バーからすぐ送信できる
- **チーム戦**
  - ロビーの設定で「個人戦 / チーム戦」を切替。チーム数は2〜6（3チーム以上も可）
  - チーム分けは **バランス（直前スコア順の蛇行ドラフト）/ ランダム / GM手動**
    （ロビーで事前に振り分け・振り直し・手動指定ができ、試合開始時に確定）
  - 勝利条件は **合計点数 / 1位獲得数 / 正解数 / 平均点** から選択。同点なら引き分け
  - 対戦中は画面上部にチーム別途中経過、右側に「個人成績」（個人順位・得点・1位数・正解数）を常時表示。
    最終結果でもチーム順位の下に個人成績を必ず表示する
  - **途中参加**: 対戦中でも新規参加できる。チーム戦では参加前に各チームのメンバー
    （対戦中は得点つき）を見て、入りたいチームを自分で選べる
  - **再参加**: 一度抜けた人が同じ端末で戻ると、保存されていた得点と所属チームがそのまま復活する
  - **退出者の扱い**: 抜けた人も名前・得点・所属チームは残り、結果画面・個人／チーム成績にそのまま載る（在室者だけで再計算しない）。最終リザルトには、その試合中に一度でも部屋にいた人（試合開始時にいた人・途中参加した人）が全員載る（試合が始まる前に抜けた人は除く）
    （参加処理では得点・所属を上書きしない）
- **GM操作**（対戦画面の右側）
  - 「残りの全員をパスして確定」: 未正解者を全員パス扱いにして即確定。既に正解した人には順位どおり得点が入る
  - 「試合を強制終了して設定へ戻る」: 進行中の問題を破棄してロビーへ戻る。ルーム・得点・所属は消えない
- **サウンドシステム**
  - BGM（Komiku / トップ・対戦・結果）と効果音。すべて外部の CC0 素材を加工して同梱
  - 正解音は Kenney の CC0 素材（金属の一撃＋階段状アルペジオ）を重ねた専用音
  - **既定はミュート**（BGM・効果音とも OFF）。右下の AUDIO SYSTEM で明示的に ON にする
    （効果音を ON にすると BGM も同時に ON）
  - 音量の既定ははっきり聞こえる側（BGM 0.75 / SE 0.85）
  - 画面右下の AUDIO SYSTEM から **BGM / 効果音の ON・OFF・音量**を切り替え（端末ごとに保存）。
    パネルは画面が変わると自動で閉じる（外側タップ・Esc でも閉じられる）
  - ブラウザの自動再生制限に合わせ、最初のタップで自動的に有効化
- パス（降参）と取り消し（確認ダイアログなし・画面左側に配置）
- ひとり練習モード（オフライン）
- 順位がひと目で分かる六角バッジ（1位=金 / 2位=銀 / 3位=銅）とスコアボード

## デザイン

- フォント: Orbitron（見出し・数字）/ Chakra Petch（UI）/ 日本語は OS フォント
- 絵文字は使わず、ラインアイコン（`src/components/icons.tsx`）と `1位` `2位` `3位` の
  六角バッジで状態を表現
- 背景は遠近グリッド＋スキャンライン＋走査線のアニメーション（`prefers-reduced-motion` 対応）
- favicon / PWA アイコンは `public/`。**2枚のネオンタイル（1=シアン / 0=マゼンタ）**をモチーフに、
  数字を `fill-rule="evenodd"` で**切り抜いた**SVG（0.6KB）から PNG を書き出し、減色して合計 9KB
  - ブラウザタブ用（`favicon.svg` / `favicon-16/32.png` / `icon-192/512.png`）は**土台なし＝背景が透ける**
  - PWA/ホーム画面用（`apple-touch-icon.png` / `icon-maskable-512.png`）は
    不透明が必要なので濃色ベタ＋セーフゾーン80%の別データ
- 効果音・BGM・フォントも `public/` 配下（`/audio`・`/fonts`）。
  ビルドすると本体は `dist/index.html` 単体（**約 454KB / gzip 131KB**）になり、
  音声は必要なときだけ読み込まれる

## 軽量化メモ

- ランタイムは **Preact（`preact/compat`）**。`vite.config.ts` の alias で `react` /
  `react-dom` を Preact に差し替えており、コードは React の hooks / `createPortal` のまま。
  これだけでバンドルが約 180KB（gzip 57KB）減る
- 音声・フォント・アイコンは `public/` に置き、URL 参照のみ（HTML への base64 埋め込みをやめた）
- 効果音はピークを揃えてから再エンコード（モノラル 80kbps）
- アイコン PNG は 160〜200 色に減色（412KB → 47KB）
- 初期表示に不要なものは `preload` しない。Firebase へは `preconnect` だけ張る

## 配信について

`npm run serve` は dist/ をそのまま（gzip + 長期キャッシュ付きで）配信する確認用サーバーです。

`npm run build` の出力は `dist/` フォルダごと配信してください
（`dist/index.html` に加えて `audio/`・`fonts/`・アイコン類が必要です）。
アプリ自体は `dist/index.html` だけで動作しますが、音声・フォント・アイコンは
同フォルダ内のファイルを参照します。

## メモ

- 問題生成はタイムスライス方式（10msごとに処理を手放す）なので、
  6桁×高難度の設定でもUIがフリーズしません。Make10の探索は時間で勝手に打ち切らず、
  見つかるまで続けます（GM／本人が「探索をあきらめる」でいつでも中止可能・全員に準備中を表示）。
  素因数分解の「3桁・素因数10個」のような原理的に不可能な指定は、無駄な探索をせず理由つきで即エラーにします。
- チャットはルーム内の直近60件のみ。GMが退出するとルームごと削除されます。
- **誰もいないルームは自動で消えます**（最後の1人が退出すれば即時、タブを閉じた場合は約30〜50秒後）。
- 在室中のルームも **最終アクセスから24時間** で自動削除されます
  （`rooms/index` の期限を見て、アプリを開いたクライアントが掃除。Cloud Functions 不要）。
- 通信が切れても再接続時に在室が自動復元され、部屋が消えていた場合はトップへ戻ります。
